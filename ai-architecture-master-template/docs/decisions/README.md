# Architecture Decision Records

Use an ADR only for durable, consequential architecture choices. Routine task
decisions belong in the relevant task file.

## Naming

`ADR-{four-digit-number}-{short-kebab-case-title}.md`

Example: `ADR-0001-use-postgresql.md`
