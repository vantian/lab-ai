# Product Terminology

| Term | Definition | Avoid |
|---|---|---|
| Todo | A single task recorded by the user | Item, card, ticket, issue |
| Active todo | A todo that has not been completed | Open ticket |
| Completed todo | A todo marked as finished but still retained | Closed issue, archived todo |
| Filter | A view selection that controls which todos are visible | Search, category |
| All filter | Shows active and completed todos | Default category |
| Empty state | Guidance shown when the current view has no visible todos | Error state |

Use “todo” consistently in product text, documentation, types, and tests.
